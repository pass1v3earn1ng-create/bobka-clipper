# Автонарезка клипов с эфиров twitch.tv/1rlandectv

После каждого эфира бот сам находит все годные моменты, режет вертикальные клипы 9:16
(вебка сверху, игра снизу, субтитры по-русски и строка по-английски помельче)
и присылает их тебе в Telegram, лучшие первыми. Лимита на количество нет.
Тебе остаётся выбрать и запостить.

Работает бесплатно на серверах GitHub, комп после эфира можно выключать.

## Как он выбирает моменты

- ты орёшь, ржёшь или материшься громче обычного, это главный сигнал;
- оживает чат: «ахах», KEKW, «жесть», «пиздец»;
- кто-то написал в чат **«клип»**, и тогда момент примерно за 20 секунд до сообщения попадёт в нарезку точно. Скажи друзьям;
- дальше бот слушает, что ты говоришь в этих местах, и оставляет самые живые.

Клип режется так, чтобы реакция была в конце, а начало попадало на паузу между фразами.

## Подключение (один раз, минут 15)

### 1. Twitch: сохранять эфиры (до следующего эфира!)
Только с компа или в браузере (в приложении Twitch этой настройки нет):
аватарка справа вверху → **Панель управления автора** (Creator Dashboard) → **Настройки** → **Трансляция** →
блок про записи (VOD Settings) → включи **«Сохранять прошлые трансляции»** (Store past broadcasts)
и **«Всегда публиковать записи»** (Always publish VODs).
Эфиры, которые шли до этого, Twitch не сохранил, и их уже не вернуть: резать можно будет со следующего эфира.

### 2. Telegram-бот
1. В Telegram открой **@BotFather** → отправь `/newbot`.
2. Имя любое (например, `bobka clips`), ник латиницей и в конце `bot`.
3. BotFather пришлёт токен вида `123456789:AA...`. Скопируй его.
4. Открой своего нового бота → **Запустить** → напиши ему что угодно.

### 3. GitHub
1. Зарегистрируйся на [github.com](https://github.com).
2. Справа вверху **+** → **New repository** → имя `bobka-clipper` → **Public** → **Create repository**.
   Public нужен, чтобы минуты были бесплатными без лимита. Токен бота при этом никто не видит, он хранится в секретах.
3. На странице репозитория нажми ссылку **uploading an existing file**.
4. Распакуй архив и перетащи в браузер **всё содержимое** папки `bobka-clipper`, вместе с папкой `.github` → **Commit changes**.
5. **Settings** → **Secrets and variables** → **Actions** → **New repository secret**:
   Name: `TELEGRAM_BOT_TOKEN`, Secret: токен из BotFather → **Add secret**.

### 4. Пробный запуск
**Actions** → слева **Нарезка клипов** → **Run workflow** → вставь ссылку на эфир
(twitch.tv/1rlandectv → Видео → Прошлые трансляции → открой эфир → скопируй ссылку) → **Run workflow**.
Первые клипы придут в Telegram минут через 15–30, дальше по одному, по мере готовности.
Лимита нет: сколько было годных моментов, столько и клипов.

В первый раз бот пришлёт число: это твой chat id. Добавь его вторым секретом `TELEGRAM_CHAT_ID`,
чтобы бот тебя не терял.

Дальше делать ничего не надо: каждый час бот проверяет канал и режет закончившиеся эфиры.

## Во время эфира
- реагируй вслух, громкие реакции ловятся лучше всего;
- случилось что-то годное? Пиши в чат «клип» (с телефона или попроси друзей);
- радио в GTA держи выключенным, иначе Twitch глушит звук в записи.

## Настройки: config.yaml
Открой `config.yaml` на GitHub → карандаш (Edit) → поменяй → **Commit changes**. Главное:

| что | зачем |
|---|---|
| `strictness` | насколько строго отбирать моменты (1 — обычно, 1.5 — только жёсткие, 0.7 — побольше) |
| `clips_max` | сколько самых сильных моментов присылать с эфира (8; «клип» из чата — всегда сверх). 0 — без лимита |
| `clips_min` | сколько клипов прислать даже с тихого эфира (3) |
| `clip_target_sec`, `clip_min_sec`, `clip_max_sec` | длина клипа: обычно 22 сек, от 18 до 30 |
| `subtitles`, `english_line` | субтитры и английская строка |
| `handle_text` | подпись канала на клипе |
| `layout`, `cam_box` | раскладка и где вебка, если автопоиск промахнулся |
| `send_clean_copy` | ещё и копия без субтитров, для монтажа в CapCut |

## Умный отбор через Claude (по желанию)
Добавь секрет `ANTHROPIC_API_KEY` (ключ с [console.anthropic.com](https://console.anthropic.com),
API оплачивается отдельно от подписки). Тогда моменты отбирает Claude: читает, что ты говоришь и что пишет чат,
решает, где смешно, и точнее выбирает начало и конец. Субтитры он тоже переводит на английский живее.
Без ключа бот работает на простых правилах.

## Если что-то не так
- **Клипы не пришли.** Actions → последний запуск → смотри шаг с красным крестиком. Готовые клипы за 5 дней лежат
  внизу страницы запуска, в **Artifacts**.
- **«нет сохранённых эфиров».** Вернись к шагу 1.
- **Вебка не там.** При первом запуске бот присылает кадр с зелёной рамкой. Если рамка мимо вебки,
  пропиши `cam_box` в config.yaml (или скинь этот кадр Claude, он посчитает цифры).
- **Ошибки в субтитрах.** Речь распознаётся на слух и иногда путает мат и сленг. Выключить: `subtitles: false`.
- **Проверять чаще или реже.** Файл `.github/workflows/clipper.yml`, строка `cron`.

## Запуск на своём компе (запасной вариант)
Нужны Python 3.12 и ffmpeg. В папке проекта:

```
pip install -r requirements.txt
python -m clipper file "D:\Видео\запись эфира.mkv"
```

Клипы появятся в папке `clips`. Чтобы они ещё и пришли в Telegram, перед запуском задай переменные
`TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`.

---
Внутри: yt-dlp и TwitchDownloaderCLI (эфир и чат), Silero VAD и faster-whisper (речь), OpenCV YuNet (лицо),
ffmpeg (монтаж). Шрифты Onest и Dela Gothic One под лицензией OFL, модель YuNet под MIT, лицензии лежат в `assets`.
